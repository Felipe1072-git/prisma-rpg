# Prisma RPG

Sistema de RPG de mesa homebrew autoral — um d20 tradicional simplificado, sem classes, onde magia e habilidades funcionam pela mesma estrutura de Mana.

Conteúdo canônico em [`docs/`](docs/index.md), gerado como site via [MkDocs](https://www.mkdocs.org/) (Material theme).

## Rodando localmente

```
pip install mkdocs-material
mkdocs serve
```
